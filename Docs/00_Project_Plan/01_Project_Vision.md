# 01 Project Vision

## الرؤية

بناء مرجع عربي عميق ومنظم لتعلم واستخدام عقد Godot 2D، مع تركيز خاص على `Node2D` وما يتصل بها عمليًا داخل مشاهد الألعاب ثنائية الأبعاد.

هذا المشروع ليس ترجمة حرفية للتوثيق الرسمي، وليس دورة عشوائية. الهدف هو إنتاج مرجع عملي يربط بين:

- التوثيق الرسمي لـ Godot 4.x.
- الفهم الصحيح لشجرة الوراثة.
- اختيار Root Node المناسب.
- تركيب Nodes مع بعضها بطريقة صحيحة.
- أمثلة عملية من ألعاب 2D.
- أخطاء المبتدئين الشائعة وكيفية تجنبها.

## الجمهور المستهدف

| الفئة | ماذا تستفيد؟ |
|---|---|
| المبتدئ في Godot | يفهم ما هي Nodes، وما الفرق بين Player و Sprite و Collision. |
| من يعرف الأساسيات | يحصل على جداول مقارنة وأمثلة تركيب صحيحة. |
| مطور ألعاب 2D | يستخدم المرجع لاختيار Node مناسب لكل حالة. |
| من ينتقل من محركات أخرى | يفهم فلسفة Godot القائمة على Scene و Node Tree. |

## نطاق المشروع

يركز المشروع على:

- `Node` و `CanvasItem` و `Node2D`.
- جميع أو معظم Nodes المستخدمة في بيئة 2D.
- Physics Nodes مثل `CharacterBody2D`, `StaticBody2D`, `RigidBody2D`, `AnimatableBody2D`, و `Area2D`.
- Collision Nodes و Shape Resources.
- Nodes الخاصة بالرسم، الإضاءة، الملاحة، الكاميرا، الصوت، المسارات، والجسيمات.
- أمثلة تركيب عملية مثل Player, Enemy, Coin, Door, Bullet, Moving Platform, Level.
- Decision Trees تساعد على اختيار Node الصحيح.
- Best Practices وأخطاء شائعة.

## خارج نطاق المشروع حاليًا

هذا المشروع لا يهدف في مرحلته الحالية إلى:

- بناء لعبة كاملة من البداية للنهاية.
- شرح GDScript كاملًا كلغة برمجة.
- شرح 3D Nodes إلا عند المقارنة فقط.
- شرح Multiplayer أو Networking.
- شرح Export للمنصات.
- تغطية Godot 3.x إلا كملاحظة تحذيرية عند وجود اختلاف مهم.

## النتيجة النهائية المطلوبة

نريد أن يصبح المستودع مرجعًا منظمًا يمكن فتحه أثناء تطوير لعبة 2D والإجابة بسرعة عن أسئلة مثل:

- ما النود المناسبة للاعب؟
- لماذا لا أستخدم `StaticBody2D` للاعب؟
- متى أستخدم `Area2D`؟
- ما الفرق بين `CollisionShape2D` و `RectangleShape2D`؟
- كيف أرتب Player scene؟
- ما أفضل شجرة Nodes للعدو أو العملة أو الباب؟

## المبدأ الحاكم

كل شرح يجب أن يجيب عن ثلاثة أسئلة:

1. ما وظيفة هذا الشيء؟
2. متى أستخدمه ومتى لا أستخدمه؟
3. كيف أركبه عمليًا داخل Scene صحيحة؟
