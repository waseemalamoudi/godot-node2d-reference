# 02 Research Methodology

## الهدف من منهجية البحث

هذا الملف يحدد كيف سنبني كل فصل في المرجع حتى يكون المحتوى صحيحًا، عمليًا، ومنظمًا.

نحن لا نريد نسخ التوثيق الرسمي أو ترجمته حرفيًا، بل نريد تحويله إلى مرجع عربي تعليمي يشرح الفكرة والاستخدام الصحيح والخطأ الشائع.

## مصادر البحث الأساسية

| نوع المصدر | الاستخدام |
|---|---|
| Godot Official Documentation | المصدر الأساسي للتحقق من تعريف Node، الوراثة، الخصائص، والتحذيرات. |
| Godot Class Reference | التحقق من أن Node يرث من ماذا، وما خصائصه ووظيفته. |
| Godot Manual / Tutorials | فهم الاستخدام العملي المدعوم رسميًا. |
| الخبرة العملية | صياغة أمثلة واقعية مثل Player, Enemy, Coin, Door. |

## خطوات البحث لكل Node

عند دراسة أي Node، نتبع التسلسل التالي:

1. فتح صفحة Godot الرسمية الخاصة بالـ Node.
2. التحقق من شجرة الوراثة.
3. تحديد هل هو Node أم Resource.
4. تحديد هل هو مرئي أم فيزيائي أم تنظيمي أم مساعد.
5. تحديد هل يحتاج Collision أم لا.
6. تحديد الأبناء الشائعين له.
7. تحديد الحالات الصحيحة لاستخدامه.
8. تحديد الحالات الخاطئة أو غير المناسبة.
9. كتابة مثال Node Tree عملي.
10. كتابة خلاصة بسيطة للمبتدئ.

## التمييز بين المفاهيم

يجب دائمًا التمييز بين:

| المفهوم | التوضيح |
|---|---|
| Node | كائن داخل Scene Tree مثل `Sprite2D` أو `CharacterBody2D`. |
| Resource | بيانات يستخدمها Node مثل `RectangleShape2D` أو `Texture2D`. |
| Scene | ملف يحتوي شجرة Nodes ويمكن إعادة استخدامه. |
| Script | كود يركب على Node. |
| Root Node | أول Node في Scene. |
| Child Node | Node داخل Node آخر. |

## منهجية الشرح

كل شرح يجب أن يجمع بين:

- تعريف رسمي مبسط.
- تفسير عملي للمبتدئ.
- مثال Node Tree.
- جدول مقارنة إذا كان هناك Nodes متشابهة.
- تحذير من الأخطاء الشائعة.
- خلاصة عملية في النهاية.

## التعامل مع Nodes غير التابعة مباشرة لـ Node2D

بعض Nodes لا ترث من `Node2D` لكنها تستخدم كثيرًا داخل مشاهد 2D، مثل:

- `Timer`
- `AnimationPlayer`
- `NavigationAgent2D`

هذه لا نضعها خطأً في قائمة “ترث من Node2D”، بل نوضح أنها Nodes مساعدة تركب عمليًا داخل مشاهد 2D.

## التعامل مع الاختلافات بين الإصدارات

عند وجود اختلاف بين Godot versions:

- نركز على Godot 4.x.
- نذكر إن كان الشيء deprecated.
- نذكر إن كان الشيء experimental.
- لا نعطي تعليمات Godot 3.x على أنها صالحة لـ Godot 4.x.

## المبدأ النهائي

أي معلومة تقنية مهمة يجب أن تكون قابلة للتحقق من التوثيق الرسمي أو من استخدام عملي واضح داخل Godot 4.x.
