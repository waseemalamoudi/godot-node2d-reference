# 04 Writing Style Guide

## الهدف

هذا الملف يحدد أسلوب الكتابة داخل المستودع حتى تكون كل الفصول موحدة، واضحة، وعملية.

## لغة الشرح

الشرح الأساسي يكون باللغة العربية.

أسماء Nodes، Classes، Resources، Properties، Methods، وأمثلة الكود تبقى كما هي بالإنجليزية.

مثال صحيح:

```text
استخدم `CharacterBody2D` للاعب الذي يتحرك بالكود ويحتاج إلى `CollisionShape2D` للتصادم.
```

مثال غير مرغوب:

```text
استخدم جسم الشخصية ثنائي الأبعاد بدلًا من كتابة اسم CharacterBody2D.
```

نشرح المعنى بالعربي، لكن لا نترجم اسم Class.

## مستوى التفصيل

المشروع يهدف إلى شرح عميق جدًا، لكن التفصيل يجب أن يكون منظمًا وليس حشوًا.

كل فقرة يجب أن تجيب عن سؤال واضح:

- ما هذا؟
- لماذا أستخدمه؟
- متى لا أستخدمه؟
- ما الذي يركب معه؟
- ما الخطأ الشائع حوله؟

## أسلوب الكتابة

| القاعدة | التطبيق |
|---|---|
| عربي واضح | لا نستخدم تعقيدًا لغويًا غير ضروري. |
| مصطلحات Godot كما هي | `Node2D`, `Sprite2D`, `Area2D`. |
| شرح عملي | نربط كل Node بمثال لعبة. |
| جداول كثيرة | خاصة في المقارنات. |
| أمثلة Node Tree | إلزامية عند شرح التركيب. |
| تحذيرات واضحة | عند وجود خطأ شائع أو استخدام غير مناسب. |

## طريقة شرح Node

عند شرح Node، لا نكتفي بالتعريف.

يجب أن نشرح:

1. ما هو؟
2. أين يوجد في شجرة الوراثة؟
3. ما وظيفته؟
4. متى أستخدمه؟
5. متى لا أستخدمه؟
6. هل يحتاج Collision؟
7. ما الأبناء الشائعون له؟
8. مثال عملي.
9. أخطاء شائعة.
10. خلاصة.

## الجداول

الجداول تستخدم عندما يكون هناك مقارنة أو تصنيف.

مثال:

| Node | الاستخدام الصحيح | الاستخدام الخاطئ |
|---|---|---|
| `CharacterBody2D` | لاعب يتحرك بالكود | جسم فيزيائي يسقط بحرية مثل كرة |
| `StaticBody2D` | أرض أو جدار | لاعب يقفز ويتحرك |
| `Area2D` | عملة أو Trigger | أرض تمنع المرور |

## أمثلة Node Tree

يجب استخدام تنسيق ثابت:

```text
Player (CharacterBody2D)
├── AnimatedSprite2D
├── CollisionShape2D
├── Camera2D
└── AudioStreamPlayer2D
```

بعد كل شجرة، نشرح لماذا كل Node موجود.

## كتابة الأخطاء الشائعة

الأخطاء الشائعة يجب أن تكون مباشرة وواضحة.

مثال:

```text
خطأ شائع: جعل اللاعب `Sprite2D` فقط.
المشكلة: `Sprite2D` يعرض صورة فقط ولا يوفر حركة فيزيائية أو تصادمًا.
الصحيح: اجعل اللاعب `CharacterBody2D` وضع `Sprite2D` كابن له.
```

## التعامل مع المصطلحات الإنجليزية

عند ذكر مصطلح لأول مرة، نكتبه كما هو ثم نشرحه بالعربي.

مثال:

```text
Root Node هو أول Node في المشهد، وكل Nodes الأخرى تكون تحته كأبناء.
```

## أسلوب الخلاصة

كل ملف تعليمي يجب أن ينتهي بخلاصة قصيرة مثل:

```text
الخلاصة: استخدم `Area2D` عندما تريد الكشف عن دخول أو لمس جسم، وليس عندما تريد جسمًا صلبًا يمنع الحركة.
```

## ما يجب تجنبه

- الترجمة الحرفية للتوثيق الرسمي.
- استخدام أسماء عربية بديلة لأسماء Godot Classes.
- وضع أمثلة غير قابلة للتطبيق.
- الخلط بين Node و Resource.
- شرح طويل بدون جداول أو أمثلة.
- إصدار أحكام مطلقة غير دقيقة مثل “لا تستخدم هذا أبدًا” دون سبب.
