# 05 Document Template

## الهدف

هذا الملف يوفر قوالب كتابة موحدة لاستخدامها في جميع فصول المرجع.

ليست كل الملفات تحتاج نفس القالب، لذلك سنستخدم أكثر من قالب حسب نوع المحتوى.

---

# قالب شرح Node واحد

يستخدم عند كتابة ملف عن Node مثل `CharacterBody2D`, `Sprite2D`, `Area2D`, أو `Camera2D`.

```md
# NodeName

## 1. التعريف المختصر

شرح بسيط جدًا: ما هو هذا الـ Node؟

## 2. موقعه في شجرة الوراثة

```text
Object
└── Node
    └── CanvasItem
        └── Node2D
            └── NodeName
```

## 3. وظيفته الأساسية

ما الذي يفعله داخل Godot؟

## 4. متى تستخدمه؟

- حالة 1
- حالة 2
- حالة 3

## 5. متى لا تستخدمه؟

- حالة خاطئة 1
- حالة خاطئة 2

## 6. هل يحتاج Collision؟

شرح هل يحتاج `CollisionShape2D` أو `CollisionPolygon2D`، ومتى.

## 7. ماذا يركب تحته؟

| Child Node | السبب |
|---|---|
| `Sprite2D` | للعرض البصري. |
| `CollisionShape2D` | للتصادم أو الكشف. |

## 8. ماذا يركب فوقه؟

هل يكون Root؟ أم Child؟ ومتى؟

## 9. مثال Node Tree

```text
Example (NodeName)
├── Sprite2D
└── CollisionShape2D
```

## 10. مثال عملي في لعبة

شرح مثال من لعبة حقيقية: لاعب، عدو، عملة، باب، منصة.

## 11. أخطاء شائعة

| الخطأ | المشكلة | الصحيح |
|---|---|---|
| مثال خطأ | لماذا يسبب مشكلة | البديل الصحيح |

## 12. مقارنة مع Nodes مشابهة

| Node | الفرق |
|---|---|
| `OtherNode` | شرح الفرق. |

## 13. خلاصة سريعة

جملة أو فقرتان تلخصان الاستخدام الصحيح.

## 14. مصادر رسمية

- Godot official documentation link
```

# قاعدة استخدام القوالب

لا يجب ملء القالب ميكانيكيًا إذا لم يكن القسم مفيدًا، لكن يجب الحفاظ على نفس البنية العامة حتى تكون الملفات متناسقة وسهلة القراءة.
