# 06 Glossary

## الهدف

هذا الملف يجمع المصطلحات الأساسية التي ستتكرر في المرجع. الهدف هو تقليل الالتباس، خصوصًا بين مفاهيم متشابهة مثل Node و Scene و Resource.

## مصطلحات Godot الأساسية

| المصطلح | الشرح |
|---|---|
| `Node` | وحدة بناء داخل Godot. كل شيء تقريبًا في المشهد هو Node: لاعب، صورة، كاميرا، جسم تصادم، صوت. |
| `Scene` | ملف يحتوي شجرة Nodes. يمكن استخدامه كمشهد كامل أو ككائن قابل لإعادة الاستخدام مثل Player أو Enemy. |
| `Scene Tree` | الشجرة التي تحتوي Nodes أثناء تشغيل اللعبة. |
| `Root Node` | أول Node في المشهد. كل Nodes الأخرى تكون تحته كأبناء. |
| `Parent Node` | Node تحتوي Nodes أخرى داخلها. |
| `Child Node` | Node موجودة داخل Node أخرى. |
| `Owner` | علاقة ملكية داخل المشهد، مهمة للحفظ داخل Scene، وتختلف عن Parent في بعض الحالات المتقدمة. |

## مصطلحات 2D

| المصطلح | الشرح |
|---|---|
| `CanvasItem` | أصل للعناصر التي تظهر في 2D أو واجهة المستخدم. يرث منه `Node2D` و `Control`. |
| `Node2D` | Node ثنائية الأبعاد لها position و rotation و scale و skew. تستخدم للعالم ثنائي الأبعاد. |
| `Control` | عائلة Nodes مخصصة للواجهات UI، مثل Button و Label و Panel. ليست بديلًا عن `Node2D` في عالم اللعبة. |
| `Transform` | بيانات المكان والدوران والحجم. في 2D تشمل position و rotation و scale. |
| `Position` | مكان Node في مساحة 2D. |
| `Rotation` | دوران Node. |
| `Scale` | تكبير أو تصغير Node. |

## مصطلحات الفيزياء

| المصطلح | الشرح |
|---|---|
| `Collision` | التصادم أو الكشف بين الأجسام. قد يعني منع الحركة أو مجرد كشف دخول منطقة. |
| `CollisionObject2D` | أصل لكائنات التصادم في 2D، مثل `Area2D` و `PhysicsBody2D`. |
| `PhysicsBody2D` | أصل للأجسام الفيزيائية مثل `CharacterBody2D`, `StaticBody2D`, و `RigidBody2D`. |
| `CharacterBody2D` | جسم مخصص للشخصيات التي تتحرك بالكود، مثل اللاعب أو العدو. |
| `StaticBody2D` | جسم ثابت مناسب للأرض والجدران والمنصات الثابتة. |
| `RigidBody2D` | جسم تحركه الفيزياء بالقوى والجاذبية والاصطدامات. |
| `AnimatableBody2D` | جسم يتحرك يدويًا لكنه مناسب للمنصات والأبواب المتحركة. |
| `Area2D` | منطقة كشف لا تستخدم غالبًا كجسم صلب، بل لاكتشاف دخول وخروج أجسام أخرى. |

## مصطلحات Collision Shapes

| المصطلح | الشرح |
|---|---|
| `CollisionShape2D` | Node داخل Scene Tree يحمل Shape Resource لتحديد شكل التصادم. |
| `CollisionPolygon2D` | Node يحدد تصادمًا باستخدام مضلع. |
| `Shape2D` | Resource يمثل شكل تصادم، وليس Node في الشجرة. |
| `RectangleShape2D` | Resource لشكل تصادم مستطيل. |
| `CircleShape2D` | Resource لشكل تصادم دائري. |
| `CapsuleShape2D` | Resource لشكل كبسولة، مناسب كثيرًا للشخصيات. |
| `SegmentShape2D` | Resource يمثل خط تصادم. |
| `WorldBoundaryShape2D` | Resource يمثل حدًا لا نهائيًا تقريبًا مثل أرض عالمية. |

## مصطلحات الرسم

| المصطلح | الشرح |
|---|---|
| `Sprite2D` | Node يعرض صورة 2D واحدة أو جزءًا من Texture. |
| `AnimatedSprite2D` | Node يعرض Animation باستخدام SpriteFrames. |
| `Texture2D` | Resource يمثل صورة يستخدمها Sprite أو عناصر رسم أخرى. |
| `Polygon2D` | Node يرسم مضلعًا مملوءًا بلون أو Texture. |
| `Line2D` | Node يرسم خطًا بسماكة وشكل. |
| `Label2D` | Node يعرض نصًا داخل عالم 2D. |

## مصطلحات عملية

| المصطلح | الشرح |
|---|---|
| Player Scene | مشهد مستقل يمثل اللاعب، غالبًا Root فيه `CharacterBody2D`. |
| Enemy Scene | مشهد مستقل يمثل عدوًا، غالبًا Root فيه `CharacterBody2D` أو نوع آخر حسب السلوك. |
| Trigger | منطقة تفعل حدثًا عند دخول جسم إليها، غالبًا باستخدام `Area2D`. |
| Hitbox | منطقة تصف مكان استقبال الضربة. غالبًا `Area2D`. |
| Hurtbox | منطقة تصف مكان تلقي الضرر. غالبًا `Area2D`. |
| Spawn Point | نقطة إنشاء كائنات جديدة، غالبًا باستخدام `Marker2D`. |

## قاعدة المصطلحات

عند كتابة الفصول، نستخدم المصطلح الإنجليزي كما هو ثم نشرحه بالعربي عند الحاجة.

مثال:

```text
`Area2D` هي منطقة كشف تستخدم لمعرفة متى يدخل جسم آخر إلى نطاق معين.
```
