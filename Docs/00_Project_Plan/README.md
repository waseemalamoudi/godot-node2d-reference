# 00 Project Plan

هذا المجلد هو نقطة البداية الحاكمة لمشروع `godot-node2d-reference`.

الغرض منه ليس شرح Godot نفسه، بل تحديد طريقة بناء المرجع العربي خطوة بخطوة قبل الدخول في الفصول التعليمية التفصيلية.

## وظيفة هذا المجلد

- تحديد رؤية المشروع وحدوده.
- توضيح منهجية البحث والاعتماد على المصادر الرسمية.
- وضع قواعد الدقة حتى لا نخلط بين Godot 3 و Godot 4 أو بين Node و Resource.
- تحديد أسلوب الكتابة بالعربية مع إبقاء أسماء Godot الأصلية كما هي.
- توفير قالب ثابت للملفات التعليمية.
- توحيد المصطلحات الأساسية.
- تحديد workflow العمل والمراجعة قبل رفع الفصول.
- وضع checklist لمعرفة متى يكون الفصل مكتملًا.

## قاعدة مهمة

لا يبدأ أي فصل تفصيلي قبل الاتفاق على نطاقه وملفاته. كل فصل يُناقش أولًا، ثم تُكتب مسودته، ثم تُراجع، وبعد الاعتماد فقط يُرفع إلى المستودع.
